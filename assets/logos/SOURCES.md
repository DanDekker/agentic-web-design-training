# Logo sources

The monochrome README tiles retain brand mark geometry from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/icons) at commit `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`. Their paths were placed on black tiles with white fills to match this repository's visual style. The Polar mark comes from [Polar's official repository](https://github.com/polarsource/polar/blob/2aef55c966b20f6d0dd8ecd50479a3f3b8dbd0fe/server/polar/backoffice/static/logo.dark.svg) at commit `2aef55c966b20f6d0dd8ecd50479a3f3b8dbd0fe`.
